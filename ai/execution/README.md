# 공통 실행·보정·평가

`common.py`는 경로·파일 해시·프로필·상태 기록, 나머지 모듈은 기존 ridge baseline·정상 보정·독립 개발 evaluator를 제공한다. 현재 비교 실행기는 [learning](../learning/README.md), 사용자 명령은 `./ai/drone-ai`다.

`cli.py`·`remote.py`의 기존 104run 계약은 과거 실행·소유권·실패 처리 회귀검증용이다. 현재 메뉴는 이 계획을 자동 실행하지 않는다. 기능시험에서 기존 봉인 snapshot을 읽더라도 새 1,200run 본학습 인수 조건을 완화하지 않는다.

서버와 Python은 명시한 프로필에서 선택한다. 제출 잠금과 실제 계산 잠금을 공유하고 GPU 작업을 중복 제출하지 않는다. 새 시도의 출력에 기록하며 기존 모델·입력·실패 증거를 덮어쓰지 않는다.
