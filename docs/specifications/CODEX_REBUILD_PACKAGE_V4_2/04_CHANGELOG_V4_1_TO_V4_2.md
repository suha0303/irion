# v4.1 → v4.2 변경 내역 — 현재 범위를 X500로 확정

문서 버전: 4.2 · 수정일: 2026-10-13

사용자 결정: 지금은 X500 기준 한 기체의 시스템을 완성한다. 다양한 실기체에 커스터마이징 가능한 파운데이션 모델은 장기 목표로 남기되, 지금의 구현 범위를 넓히지 않는다.

## 변경하지 않은 핵심

LSTM·Transformer 미래 예측 구조, persistence/ridge baseline, 기본 10Hz·100→10·4-target 설정, 60초/segment 문맥의 의미, 정상 선정·분할·calibration 원칙, 예측 발행/실측 채점 시각, 내부 truth 차단, 독립 정상/이상 평가, 기존 열화와 급성 고장의 구분을 유지했다. 앞서 삭제한 학습 과제와 18절은 되살리지 않았다.

모터/ESC·프로펠러·배터리/열·바람의 핵심 물리 수식과 인과 전처리도 유지했다. 실제 byte 보존 구간은 `checks/baseline_provenance.json`에 기록했다. 설정 범위 설명·데이터 입력·분할·CLI는 이번 사용자 요청에 맞춰 바뀌었으므로 전체 본문이 무변경이라고 주장하지 않는다.

원시 DRONE-RAW/metadata/watermark 2.0, evaluation event 2.1, AI forecast/decision 3.0의 의미·예시는 유지했다. 문서 버전 4.2는 모델 학습 완료나 새 학습 가중치 배포를 뜻하지 않는다.

## 구현 증거와 문서 증거

이번 변경은 전달 명세·설명·문서 검사기의 수정이다. 실제 PX4 빌드·SITL·AI 학습/검출 실험·실기체 검증은 실행하지 않았다. 원본 v4.1 ZIP과 두 독립 첨부 명세는 수정하지 않고 별도 v4.2 파일을 만들었다.
