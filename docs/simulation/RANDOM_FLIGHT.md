# 연속 무작위 비행 random-continuous-v3

2026-10-30 GUI 검토에서 발견된 문제: v2는 체크포인트마다 속도가 0이 되어
감속·정지가 반복됐다. 현재 구현은 위치 경유점 정지가 아닌 **연속 조종 입력**을
생성한다. 기존 시연은 사용자 요청으로 종료했고, 새 비행·수집은 시작하지 않는다.

## 움직임과 제한

- 현재 이동 속도에서 다음 속도 벡터로 연속 변화한다. 입력 전환 간격은 8~18초이다.
  직진에 가까운 조종, 완만한 선회, 큰 선회와 가감속을 seed별로 섞는다.
- 위치는 속도 명령을 적분하여 계산한다. 표시되는 점은 입력이 바뀌는 위치이며
  도착 후 기다리거나 정지하는 목표점이 아니다. **중간 정지와 호버링 유지 구간은 없다.**
- 첫 12초는 3m 이륙 위치에서 가속하고 마지막 10초에만 정지하도록 감속한다.
  마지막 위치에서 기존 PX4 착륙 명령을 사용한다. 임무 180/900초에는 이 두 구간이 포함된다.
- 무풍 기준 내부 속도 목표는 1.2/1.95/2.4/3m/s를 섞으며 선회 중에도 최소 0.9m/s를
  유지하도록 전체 곡선을 검사한다. 큰 방향 전환도 속도를 끊지 않고 여러 선회로 이어진다.
- 바람 조건에서는 수평 상한을 `min(3, 4.5 - 평균풍속 - 3*돌풍표준편차)` m/s로 낮춘다.
  이동 중 최소속도 기준도 해당 상한의 30%이다. 이는 확률적 돌풍의 절대 보장이 아니다.
- 출발점 반경 제한·귀환 의무가 없다. 이전 20~100m 구간거리 조건도 사용하지 않는다.
  이동 거리는 연속 속도와 조종 지속 시간의 결과이며 마지막 위치는 출발점과 무관하다.
- 상승·하강 입력을 수평 선회와 함께 변화시키며, 두 동작을 모든 run에 포함한다.
  전체 곡선의 고도는 3~30m 내에 있도록 검증한다. 생성 입력의 수직속도는 최대 0.65m/s이다.
- yaw는 대체로 진행 방향을 따르면서 일부 구간에 ±30도 편차를 섞고 연속적으로 회전한다.
  roll/pitch는 PX4가 계산한다. 실제 사람 조종 데이터를 학습한 모델은 아니다.
- 속도 입력을 5차 다항식으로 연결하고 적분하므로 위치·속도·가속도·jerk가 이어진다.
  수직속도 ≤1.2m/s, 3차원 가속도 ≤1.4m/s², jerk ≤1.5m/s³, yaw rate ≤0.6rad/s를 유지한다.
- 속도 최소값은 속도 벡터 사이의 선분에서 해석적으로 검사한다. 고도는 적분 곡선의
  Bezier 제어점 convex hull로 전체 구간을 보수적으로 제한한다. 유한 샘플만으로 안전을 판정하지 않는다.
- 기존 10Hz 위치·속도·가속도 feed-forward, 위치 오차 2m 중단과 기존 추종 적격성 기준은 유지한다.
- 무작위 경로의 전체 곡선과 100m 여유를 덮는 명시적 box 충돌 지면을 만든다.
  Gazebo DART의 plane은 표시 크기를 늘려도 실제 충돌 범위가 2,100m로 고정되므로
  장거리 경로의 착륙 지점에서 지면을 통과하던 문제를 수정했다. 지면 높이는 z=0이다.
- 수집용 PX4의 `MPC_LAND_SPEED`는 0.3m/s이며, 이륙 전 실제 파라미터 응답을 검증한다.
  착륙 중에도 heartbeat를 유지하고, LAND 모드에는 OFFBOARD 위치 명령을 보내지 않는다.
  착륙 제한 300초·물리 모델 적격성·재시도 상한은 유지한다.

`program` 행은 `[t, north, east, down, yaw, vn, ve, vd]`이다. 이는 경로 설정 형식이며
원시 관측 데이터 schema는 변경하지 않았다. 기본/혼합 비행, 기체·배터리·추진 모델도 유지한다.

## GUI 확인

첫 명령은 계획 파일만 만들며 비행하지 않는다.

```bash
./simulation/capstone-sim preview plan --seed 20261030 --duration 900
```

기본 계획은 `simulation/artifacts/random-continuous-v3/preview.json`이다.
다른 seed는 `--plan artifacts/random-continuous-v3/preview-SEED.json`으로 별도 저장한다.

사용자가 다시 시연을 요청한 후에만 다음을 실행한다.

```bash
./simulation/capstone-sim preview fly --plan artifacts/random-continuous-v3/preview.json
```

기체 한 대·한 번·1배속이며 QGC 기본 UDP 14550을 사용한다. Gazebo 카메라는 렌더링
기체를 기다린 뒤 따라간다. 시연은 `demo_only`이며 수집 데이터 인수 검사에서 제외된다.
실행기 진단용 임시 run 기록은 남는다. setup·수집·인스턴스 잠금을 존중한다.
끝나면 시연이 생성한 Gazebo·PX4를 닫고 별도로 연 QGC는 유지한다.

## 데이터 준비와 검증 상태

작은 무작위와 v2 정지형 무작위는 모두 현재 생성·실행에서 거부한다. 과거 데이터,
계획과 성공·실패 증거는 그대로 보존한다. 새 `normal_variation_revision`은
`balanced300-random-continuous-v3`다.

새 1,200개 **미실행 계획**은 `Data/operations/plans/random-continuous-v3-20261030/cases.json`이다.
기본412/혼합308/새 무작위312/비교·이상168 구성과 용도별 비율을 유지한다.
실행·수집 승인 필드는 false이고 현재 수집 작업을 만들지 않았다.

오프라인 수치·회귀 검사와 실제 SITL 검증은 구분한다. 새 경로의 실제 추종·착륙,
15분 동안의 배터리 여유와 사람이 느끼는 조종 자연스러움은 다음 GUI 검토 단계에서
확인해야 한다. 이번 구현 완료를 데이터 수집 성공이나 실기체 검증으로 보고하지 않는다.

2026-10-30 수집 중 발견한 착륙 실패의 원인·수정과 최신 실제 재시험 상태는
[안정성 점검 보고서](reports/flight-stability-20261030/REPORT.md)를 따른다.
