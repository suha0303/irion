# 순간 풍속 상한 5m/s의 시간변동 환경

사용자가 지정한 상한은 **물리적으로 적용되는 3차원 바람 벡터의 크기가 모든 시각에서 5m/s 이하**라는 뜻이다. 평균풍에 무한 지지 Gaussian 돌풍을 더하는 방식으로 이 상한을 주장하지 않는다. 현재 모델은 `bounded-latent-ou-c2-enu-v1`이다.

| 환경 | 운용 구간 | 기본 생성 범위 |
|---|---|---|
| `calm` | 0m/s | 항상 0 |
| `low` | 0 < 풍속 ≤ 2.5m/s | 0.25~2.25m/s |
| `strong` | 2.5 < 풍속 ≤ 5m/s | 2.75~4.75m/s |

구간 경계에 수치 여유를 두기 위해 기본 중앙값을 1.25/3.75m/s, 변화폭을 각각 1m/s로 동결했다. 이 변화폭은 표준편차가 아니다. 강한 바람을 선택하면 풍속과 방향이 비행 중 실제로 변한다. 무풍에서는 실제 바람 벡터가 항상 0이다.

## 생성식과 연속성

기존 `physics/wind.hpp`의 exact-discrete OU 식은 바꾸지 않았다. 새 모델에서는 이 식으로 **무차원 잠재 상태** 세 개를 만든다. 잠재 상태의 OU 매듭 표준편차는 1, 상관시간은 2초, 매듭 간격은 1초다. 매듭 사이를 5차 smoothstep으로 연결하므로 잠재 곡선과 변환된 바람은 C2 연속이다. 매듭 사이의 보간은 분산을 정규화하지 않으며, 실제 바람의 표준편차·상관시간은 별도로 측정한다.

```text
s(t) = 중앙값 + 변화폭 × tanh(α z_speed(t))
방향(t) = 기준 방향 + 60° × tanh(α z_direction(t))
고도각(t) = 15° × tanh(α z_elevation(t))
w_ENU(t) = s(t) [cos(고도각) sin(방향), cos(고도각) cos(방향), sin(고도각)]
```

`α`는 0.5~1.5의 **무차원 변동 강도**이며 기본값은 1이다. 방향은 바람이 **향하는 방향**으로 북쪽 0°, 동쪽 90°다. ENU 벡터는 동·북·상향 순서이고 단위는 m/s다. 이 정의에서 벡터의 크기는 `s(t)`이므로 모든 잠재값과 보간 시각에서 해당 풍속 구간을 유지한다. 결과 로그나 품질값을 사후에 잘라 상한을 맞추지 않는다.

네이티브 플러그인은 이 함수를 매 물리 단계에 평가한다. 구간을 벗어나거나 비유한 값이 생기면 실행을 실패 처리한다. 누적 물리 단계 수, 풍속 극값과 최대 단계 간 변화도 평가 truth에 기록한다. 단위시험은 극단 잠재값, 1ms 평가, 매듭 부근 연속성, seed 및 평가 간격 독립성, ENU 방향을 검사한다.

이는 범위가 명확한 공학적 환경이다. 실측 기상 스펙트럼, Dryden 모델 또는 실제 X500 풍동 정확도에 맞춘 모델은 아니다.

## 경로와 실제 상대 대기속도

현재 bounded 무작위 경로는 `random-continuous-v6-bounded-wind`다. 계획은 실제 seed의 바람을 미리 보고 고르지 않는다. 무풍/약풍/강풍의 가능한 **3차원 바람 전체 집합**을 반경 0/2.5/5m/s의 공으로 보수적으로 감싼다.

```text
계획 상대속도 ≤ 지상 3차원 속도 + 바람 집합 반경 ≤ 7m/s
무작위 수평 속도 상한 = min(3, sqrt((7 - 바람 반경)^2 - 1.2^2))
```

강풍에서 수평 상한은 1.6m/s다. 실제 1m/s 이상 속도 도달, 순항 중 상한의 30% 이상 이동, 중간 정지 금지, 상승·하강, 공간·속도 다양성과 기존 가속도·jerk·yaw 제한을 유지한다. 기동을 호버로 대체하지 않는다. 기본·혼합 기동도 도입/종료 구간의 미분을 포함해 검증한다.

실제 상대 대기속도는 `지상속도 − 실제 바람`의 크기로 검사하며 기존 8m/s 모델 제한과 로터 유입비 0.1 제한을 유지한다. 위치·yaw 추종, 전압 12.4V, SOC 0.2, duty 0.9, common19 기록 공백 0.5초 기준을 완화하지 않는다. 프로필의 바람 범위 보장은 새 seed의 비행 성공이나 실기체 정확도 인증을 뜻하지 않으며 각 run은 기존 적격성 검사를 통과해야 한다.

## CLI와 계획 설정

다음은 X500 collection 실행 옵션의 예시다. 이 문서 작성으로 수집 캠페인을 시작하지 않는다.

```bash
./simulation/capstone-sim run --configuration collection --scenario hover_normal \
  --wind-environment strong --wind-direction-deg 0 --wind-variation 1 \
  --duration 480 --seed 94108 --real-time-factor 2
```

동결된 operation JSON에는 기존 필드를 유지하면서 다음 설정을 추가한다. 이때 기존 `wind_e`, `wind_n`, `gust_sigma`는 0으로 두고 혼합하지 않는다. JSON 프로필과 CLI 환경 옵션을 동시에 지정하면 거부한다. CLI 환경 선택은 기본 시나리오의 기존 바람 설정을 새 프로필로 대체한다. 옛 무작위 v3/v4/v5 경로를 새 환경으로 조용히 재해석하지 않고 거부한다.

```json
"wind_profile": {
  "revision": "bounded-latent-ou-c2-enu-v1",
  "environment": "strong",
  "direction_deg": 0.0,
  "variation": 1.0
}
```

`flight_program.build`는 이 프로필이 있는 무작위 계획에 v6를 선택한다. 기존 v3/v4와 미완료 OU v5의 숫자·의미를 바꾸어 새 환경으로 재해석하지 않는다. 새 프로필을 옛 무작위 경로에 붙이면 거부하며 새 v6 계획을 만들어야 한다. 양의 Gaussian `gust_sigma`를 가진 옛 계획은 현재 producer의 비행 대상에서 명시적으로 거부한다. 원래 소스·계획·원시 자료와 재현·회귀용 수치 의미는 보존한다. 고정풍 `gust_sigma=0`은 별도 회귀로 구분한다.

`evaluation/scenario.json`의 `wind_profile`, `wind_model`, `wind_support_status`와 evaluator용 wind trace가 모드를 구분한다. 원시 관측/C9 schema와 신경망 19개 입력에는 풍속 프로필·잠재 상태·건강 파라미터를 추가하지 않았다. CMU 배터리와 추진계 endpoint, 센서 잡음 및 기존 전기·열 폐루프 연산도 유지한다.

## 검증 자료의 구분

현재 유한 개발 행렬은 정상 9기동×3환경 27조건, 다른 seed/풍향/변동 강도 5조건, 고정풍 회귀 3조건, 강풍 열화 5조건의 40조건이다. 각 임무는 480초이며 초기 SOC 0.90, 초기·외기 298.15K, 추가 탑재 0kg이다. 생산·학습·보정·독립 AI 평가는 이 행렬에 포함하지 않는다.

이전 고정풍의 32개 성공과 2개 실패, 사용자 정의 확인 전에 완료한 평균풍 OU 3개 참고 실험을 보존한다. OU 3개는 `superseded`이며 새 bounded 조건의 성공 수로 세지 않는다. 새 실행·실패·재시도·원시 자료·봉인은 `simulation/artifacts/wind-bounded-support-20261107/validation-01/`에 별도로 남긴다.

2026-11-07 최종 producer에서 **40/40조건**이 모두 통과했다. 새 환경 프로필 37조건과 고정풍 회귀 3조건이며, 실패·재시도는 0회다. 실제 임무 길이는 480.000~480.097초, 실제 배속은 1.991~1.999배였다. 약풍의 물리 단계 극값은 0.251393~2.246727m/s, 강풍은 2.750475~4.749848m/s였다. 임무 안 모델 범위 이탈은 0표본이며 임무 전·후 범위 이탈 원자료도 보존했다.

Python 220개·Ruff·mypy와 기준/현재 네이티브 시험 각 7개가 통과했다. 마지막 봉인·반납 검사 32항목과 잠금 34개 반납도 확인했다. 동일 절대 시각의 바람은 열화 대조 5개 모두 정확히 같았으나 이륙 시각에 84~180ms 차이가 있어 임무 위상이 완전히 같은 대조로 해석하지 않는다. 전체 조건, 수치, 보존 자료와 검증 한계는 [최종 보고서](reports/wind-bounded-support-20261107/REPORT.md)를 따른다.

5개 비교의 임무 상대 바람 차이는 RMS 최대 0.548667m/s, 순간 최대 3.247137m/s다. 이 차이를 무시하거나 평균 전력 차이를 순수한 건강 효과로 단정하지 않는다. **현재 바람 지원 완료와 paired 수집 준비 완료는 별개다.** 향후 예비 paired 인수 전 임무·날씨 원점 정렬 정책과 실제 차이 검사 기준을 확정해야 한다. 이번 40편은 개발 참고 자료로만 보존한다.
