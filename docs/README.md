실제 파일 배치는 [루트 안내](../README.md), 다른 컴퓨터의 수집·정제 설치는 [설치 안내](data/PORTABLE_SETUP.md)를 따른다. 범주 이동용 호환 링크는 사용하지 않는다. 과거 기록은 로컬 `docs/archive/`와 운영 보고서에 보존하며 소스 클론에 포함하지 않는다. 거기에 적힌 옛 절대 경로·revision은 당시 계보 기록으로 보존하고 새 실행 계획으로 간주하지 않는다.
