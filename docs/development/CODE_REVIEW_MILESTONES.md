# 전체 최신 코드 검수와 리팩토링

시작: 2026-11-15. GitHub: https://github.com/suha0303/irion

## 작업 원칙

- 실제 개발 원본은 루트의 `ai/`, `Data/`, `simulation/`, `docs/`와
  `irion-upload/UI/`다. `irion-upload`는 GitHub 업로드용 체크아웃이다.
- 배포에 포함되지 않는 학습, 평가, 수집, 시뮬레이션, 설치, 운영 도구,
  테스트까지 최신 자체 소스를 검수한다. 외부 라이브러리와 생성물은 구분한다.
- 이전 실행·평가·모델·원시 로그·동결 계약은 증거다. 최신 검수 대상에서
  분리하되 실행 중인 참조나 해시를 깨뜨리는 삭제·이동은 하지 않는다.
- Google Python Style Guide를 Python 기준으로 적용한다. TS/JS·C++·셸은
  해당 언어의 타입, 자원 관리, 중복, 복잡도, 오류 처리를 함께 검수한다.
- 포맷만 바꾸는 변경과 동작을 바꾸는 변경을 분리한다. 성능 개선은
  반복 I/O·불필요한 메모리·계산의 근거를 남기고 결과 동등성을 확인한다.
- 테스트는 큰 마일스톤 완료 시 관련 묶음으로 실행한다. 실패 수정이나
  새 위험이 생긴 경우에만 해당 검사를 다시 실행한다. GPU 학습·실제 비행은
  소프트웨어 회귀 검사로 대체하거나 통과했다고 주장하지 않는다.
