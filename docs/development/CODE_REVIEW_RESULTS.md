## 공개 CI와 로컬 증거 검사

최초 push의 GitHub Actions는 101 실패·251 통과였다. 새로 올라간 시험들이
Git에서 제외한 승인 기록, 원시 회차 상태, AI 환경 및 native 환경을 요구했다.
수정 소스를 깨끗한 복사본에서 실행해 남은 86건이 모두 이 의존성 때문임을
확인하고, 해당 39개 함수에 `local_evidence` 표식을 붙였다.

기본 로컬 Data 전체 검사에서는 이 시험들을 계속 실행한다. 공개 CI만
`-m "not local_evidence"`로 구분한다. 이를 통과나 skip으로 숨기지 않고
253 통과·86 deselected로 보고한다. 모델 가중치나 로컬 승인 자료를 공개해
시험을 통과시키지 않는다. CI에는 Python 스타일 검사와 프런트엔드
포맷·시험·빌드를 추가했다. 보고서만 바뀌면 기능 검사를 반복하지 않도록
소스/계약/워크플로 경로 필터를 사용한다.
