# 로컬 실기체 분석 구현 체크리스트

기준일: 2026-11-15 KST. 사용자가 승인한 범위는 GPU 서버 없이 실행하는 최신 16종 선택,
PX4 ULog·ArduPilot BIN 입력, 실기체 프로파일, CPU 적응 학습 및 설치형 배포다.
2026-11-15 추가 요구: 로컬 GPU 적응 학습은 RTX 3050급을 성능 목표 기준으로 삼고,
현재 RTX 4060 Laptop 노트북에서 검증한다. 상세 시간 예산과 미구현 항목은 아래에 구분한다.
실기체 분석을 위한 작업이다. 사용자 추가 승인에 따라 PX4/ArduPilot SITL의 시동 없는 통신 시험을 수행한다. 원격 GPU·기존 평가 재튜닝은 시작하지 않는다. 2026-11-15 추가 사용자 승인으로 별도 X500 정상 20회 및 이상 4회 시험 수집을 수행한다. 기존 생산용 데이터에는 혼합하지 않는다.
