# 로컬 실기체 분석 구현 체크리스트

기준일: 2026-11-15 KST. 사용자가 승인한 범위는 GPU 서버 없이 실행하는 최신 16종 선택,
PX4 ULog·ArduPilot BIN 입력, 실기체 프로파일, CPU 적응 학습 및 설치형 배포다.
실기체 분석을 위한 작업이다. 사용자 추가 승인에 따라 PX4/ArduPilot SITL의 시동 없는 통신 시험을 수행한다. 생산용 SITL 수집·원격 GPU·기존 평가 재튜닝은 시작하지 않는다.
체크 표시는 코드뿐 아니라 해당 범위의 실행 증거가 있을 때만 완료로 바꾼다.
완료 표시는 로컬 기능 구현·합성 시험 범위이며 실기체 성능이나 설치형 배포 완료를 뜻하지 않는다.

## 현재 작업과 재개 지점

- 소스 검수(2026-11-15): Google Python 기준 가독성 정리, 전체 런 중복 로딩 감소,
  NPZ 파일/재생 자원 관리, UI 지연 로딩, 공개 clone 배포 경로를 개선했다.
  기능 시험과 실기체 검증의 구분은 유지한다. 기존 RC12 압축 파일은 그대로다.
  전체 범위·검사·보존 예외: `docs/development/CODE_REVIEW_RESULTS.md`.
- 후속 M5·M6 완료: UTF-8 파일 계약, 외부 명령의 종료 코드 처리 의도,
  공개 API 타입·단위·오류와 주요 클래스 책임을 명시했다. 계산과 기체 판정
  기준은 동일하다. 현재 결과: `docs/development/CODE_REVIEW_FOLLOWUP.md`.
- 후속 M7·M8: 긴 행·이름·import·모듈 설명 정리. 현재 코드 스타일 진단
