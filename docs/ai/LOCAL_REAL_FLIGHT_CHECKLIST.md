## 기본 파인튜닝 절차

**V0.2 실기체 후보의 기본값은 출력층 적응, 같은 제어기 기준의 정상 보정, 독립 평가 순서다.** 기체 정보가 확인된 경우 기체별로 나눈다. 현재 로그의 두 제어기 그룹은 따로 적응·보정하며, 실제 프레임이 몇 대인지는 추가 자료로 확인한다.

1. **역할을 먼저 고정한다.** 동일 원본 파일, 같은 기체·제어기와 수집 날짜, 같은 비행에서 파생된 구간·재생·변형을 묶는다. 정상 학습, 별도 정상 보정, 독립 정상·이상 평가 사이에 묶음과 원문 해시가 겹치지 않게 한다. 각 역할의 파일·날짜·해시를 남긴다.
2. **출력층부터 적응한다.** 기본 선택은 비행 중 LSTM 128×4다. 비행 중 모델은 10 Hz 연속 이력에서 학습 시작점을 1초 간격으로 뽑는다. 비행 종료 후 모델은 초기 10초를 관측 이력으로 사용하고 이후 실측 전압으로 마지막 선형 출력층을 적응한다. 원본 인코더·디코더·스케일러를 고정하고 출력층에 원본 가중치를 기준으로 한 릿지 적응을 적용한다. 이번 기본 벌점은 `0.01`이며 정상 학습 원본 파일에 같은 가중치를 준다. 원본, 적응 후보, 직전값 유지를 공통 평가 프레임에서 비교한다.
3. **예측을 고정한 다음 판정 기준을 보정한다.** 보정 전용 정상 로그에서 각속도 잔차 중심·공분산과 전압 잔차 척도를 계산한다. 두 점수의 경험적 **99백분위**를 기본 상한으로 사용한다. 비행 중 판정은 기존 EMA, **3초 연속 초과**, 임계값의 **70% 미만 10초 연속 해제**를 적용한다. 종료 후 모델은 정상 로그별 구간 점수 최댓값의 경험적 99백분위를 사용한다. 보정 파일은 후보 번들 해시, 원본 해시, 입력 방식과 프로파일, 분할 근거에 연결한다. 이번 12S 추정과 로그의 `BATT_CAPACITY`는 실측 팩 확인이 필요한 실험 입력이다.
4. **채택은 평가 뒤에 판단한다.** 동일 예측의 기존 기준과 새 기준으로 정상 오경보 시간·횟수, 이상 검출·시점, 실제 판정 가능 구간을 비교한다. 동일 자료의 정상 오경보 감소와 독립 이상 검출 유지 여부를 각각 확인한다. 현재 두 제어기용 후보의 실기체 이상 성능은 검증 대기다.
